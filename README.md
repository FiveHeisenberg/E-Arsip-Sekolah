# 📚 E-Arsip Sekolah

E-Arsip Sekolah adalah aplikasi berbasis **Flutter** yang dirancang untuk membantu sekolah dalam mengelola arsip secara digital, sehingga proses pencarian, penyimpanan, dan pengelolaan dokumen menjadi lebih mudah, cepat, dan efisien.

## 🚀 Fitur Utama
- 📂 Manajemen arsip digital  
- 🔍 Pencarian arsip dengan mudah  
- 🏷️ Kategori dan pengelompokan arsip  
- 👩‍🏫 User friendly untuk guru maupun admin sekolah  
- ☁️ Penyimpanan berbasis cloud (opsional sesuai implementasi)  

---

## 🛠️ Teknologi yang Digunakan
- [Flutter](https://flutter.dev/)  
- [Dart](https://dart.dev/)  
- [Firebase / MySQL] *(sesuaikan dengan backend yang dipakai)*  
- [Provider / GetX / Bloc] *(state management sesuai implementasi)*
